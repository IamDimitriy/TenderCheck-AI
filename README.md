# Проверка цитат в ответе языковой модели

Небольшой пример для строительной закупки. Откройте [исходные данные](example.json): в вымышленном договоре указан аванс 15 %. Если модель уверенно назвала срок оплаты, как быстро понять, есть ли он в договоре?

Код находит дословную цитату на указанной странице, замечает неверный номер страницы и показывает, когда фразу в документе найти не удалось. Все страницы и примеры ответов в репозитории вымышлены.

| Что указано в ответе | Результат на тестовых страницах |
| --- | --- |
| Аванс 15 %, стр. 2 договора | Цитата подтверждается на стр. 2 |
| Обеспечение 5 %, стр. 2 договора | Цитата найдена на стр. 3 того же договора |
| Оплата в течение трёх рабочих дней, стр. 2 договора | Такой цитаты в договоре нет |

## Запуск за минуту

Нужен только Python 3.9 или новее. Выполните из корня репозитория:

```sh
python verify.py
python ask.py "Какой аванс предусмотрен?"
python -m unittest -v
```

Первая команда сверяет три подготовленных ответа с текстом. Вторая показывает, какие страницы будут переданы модели. Обе работают офлайн. Третья запускает тесты, включая неверный документ, изменённую сумму и некорректный ответ API.

## Попробовать самому

В первом объекте массива `claims` в [example.json](example.json) замените 15 на 25, оставив страницы в `pages` без изменений. Запустите `python verify.py` ещё раз: теперь первая цитата тоже потеряет подтверждение. При этом изменение регистра или неразрывный пробел перед знаком процента ничего не сломают.

- [verify.py](verify.py) сравнивает цитату в пределах названного документа. Флаг `--json` выводит машинный отчёт. Флаг `--strict` возвращает код 1, если хотя бы одна ссылка не подтверждается. На исходном примере это ожидаемое поведение.
- [ask.py](ask.py) ищет совпадения по словам вопроса и отбирает до двух страниц из примера. Для вопроса про аванс выбирается страница 2. При желании фрагменты можно передать в Yandex AI Studio одним запросом.

## Ответ от модели

В окружении должны быть `YANDEX_API_KEY` и `YANDEX_MODEL_URI` с полным URI доступной вам модели. Команда ниже выполняет один тарифицируемый запрос с выбранными вымышленными страницами. Без совпадений вызов пропускается.

```sh
python ask.py "Какой аванс предусмотрен?" --live
```

Программа запрашивает документ, страницу и цитату в формате JSON и сверяет ответ с переданными страницами. Статусы `wrong_page` и `unverified` видны прямо в результате. В тестах HTTP-ответ заменён фикстурой. [Документация Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/text-generation/api-ref/TextGeneration/completion)

## Что доказывает проверка

Она отвечает на один вопрос: встречается ли фраза в указанном месте. Если модель привела настоящую цитату про обеспечение в ответ на вопрос про аванс, ссылка формально пройдёт проверку. Правильность толкования условия требует отдельной оценки.
